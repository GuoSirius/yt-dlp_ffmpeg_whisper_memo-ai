## 修复 Windows 下 yt-dlp UnicodeEncodeError (latin-1 编码)
- **问题**：Python 版 yt-dlp 下载腾讯视频等含中文页面时，requests 库报 `UnicodeEncodeError: 'latin-1' codec can't encode`
- **原因**：Windows 默认编码 latin-1 无法处理中文字符，requests 库在提取网页时使用该编码
- **修复**：
  - Python 版：`base_cmd` 添加 `-X utf8` 参数，强制 Python UTF-8 模式（`process_videos.py` line 1141）
  - JS 版：子进程 `env` 显式设置 `PYTHONUTF8: '1'` 和 `PYTHONIOENCODING: 'utf-8'`（`process_videos.js` line 1227）
- **验证**：语法检查通过（py_compile + node --check）
- **提交**：`ebbdd2c`
