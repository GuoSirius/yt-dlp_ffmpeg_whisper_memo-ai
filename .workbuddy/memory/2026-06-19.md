## 修复 --step analyze --force 单独执行无效

- 根因：`--step analyze` 时 `transcribe` 本轮未执行，`result.transcribe.status = 'skipped'`，analyze 分支入口条件 `status == 'success'` 永不满足，`--force` 也无法生效
- 修复：在 analyze 分支入口前，若 transcribe 未执行但磁盘 `transcripts/{sheet}/{stem}.txt` 存在，则回退读取并将 `result.transcribe` 设为 success，再正常进入 analyze 逻辑
- 影响：Python `processOneTask`（~2688 行）/ JS `processOneTask`（~2338 行）
- 提交：24d2fa5

## 修复 Git 历史大文件推送失败

- 发现历史提交中混入了 290MB 的 `.incomplete` 模型文件（faster-whisper 缓存），被 GitHub 拒推。
- 使用 `git filter-repo --force --strip-blobs-bigger-than 100M` 从历史中彻底清除，并备份了 `.git.backup`。
- git-filter-repo 会删掉 origin remote，需在本地终端重新 `git remote add github ...` 后 `--force` 推送。
