## 修复 Git 历史大文件推送失败

- 发现历史提交中混入了 290MB 的 `.incomplete` 模型文件（faster-whisper 缓存），被 GitHub 拒推。
- 使用 `git filter-repo --force --strip-blobs-bigger-than 100M` 从历史中彻底清除，并备份了 `.git.backup`。
- git-filter-repo 会删掉 origin remote，需在本地终端重新 `git remote add github ...` 后 `--force` 推送。
