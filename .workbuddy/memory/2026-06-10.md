## .env.example 变更权限标注 (22:25 - 22:28)

### 需求
用户要求明确标注每个配置项的变更权限，方便后续修改。

### 标注体系
| 标记 | 含义 | 示例 |
|------|------|------|
| 【自由】 | 可随意变更为任意合法值 | EXCEL_FILE, YOUTUBE_PROXY, WHISPER_MODEL |
| 【调序】 | 只能从固定集合中增减/排序 | PLATFORM_PRIORITY |
| 【关联】 | 占位符需与 PLATFORM_PRIORITY 的 key 名一致 | URL 模板中的 {youtubeId} |
| 【固定】 | 除非 Excel 列名改变，否则不应修改 | COL_ID=extra.id 等 |

### PLATFORM_PRIORITY 专项说明
- 可选值集合（固定，与平台列名后缀对应）：
  - `bilibiliBvid` → B站 BV 号
  - `youtubeId` → YouTube 视频 ID
  - `tencentVid` → 腾讯视频 VID
  - `youkuId` → 优酷视频 ID
- 可以：调整顺序（排前面的优先）、增减条目（只保留需要的平台）
- 不可以：使用集合之外的值（如 tiktokId、douyinId）

### 修正
- 修复 YOUKU_URL_TPL 域名错误 (v.qq.com → v.youku.com)
