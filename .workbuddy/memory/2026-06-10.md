- **并发 + 重试 + 报告增强**（14:18）：
  - `--concurrency N`：多线程并发下载/转码（ThreadPoolExecutor），默认 1，建议 2~3
  - `--retry N`：每个步骤失败后最大重试次数，默认 0
  - `--retry-delay S`：重试间隔基数（秒），指数退避 5→10→20→40...
  - 智能重试：网络错误/超时可重试，404/403/视频已删除等永久错误不重试
  - `--dry-run`：干跑模式，仅列出任务清单及已有文件状态
  - `--retry-failed report.json`：从历史报告加载失败项重新执行
  - 报告机制：`reports/report_TIMESTAMP.json`，含 per-video 详细状态、错误信息、摘要统计
  - Excel 批量写回：所有识别文本统一收集后单线程写入，避免 openpyxl 线程安全问题
  - 故障排查：控制台打印失败/异常详情，报告 JSON 可直接用于 `--retry-failed` 重跑
- 数据量：YouTube视频 19 条 + 普诺赛中文站 72 条 = 91 条视频任务
